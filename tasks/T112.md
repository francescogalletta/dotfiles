## Goal

Reduce global `CLAUDE.md` (currently ~145 lines, symlinked to `~/CLAUDE.md`, loaded into every conversation). Every line is a tax on context and on agent attention. Audit and remove lines that:

1. Restate Claude Code defaults (no marginal value).
2. Duplicate information derivable from project state (alias tables that just repeat `zshrc`).
3. Are historical breadcrumbs no longer referenced by hooks, skills, or behaviour.
4. Are easier to look up from `--help` than to embed in the system prompt.

Keep:
- Non-negotiable safety rules (Host Safety, Containerised Projects, Agentic Safety).
- Project documentation convention (ADR/PRD/TASKS) — hooks and skills reference it.
- Behaviour rules that override Claude defaults (tone, trade-off table convention, run-tests-yourself).

## Acceptance Criteria

- [ ] `CLAUDE.md` is ≤ 80 lines (≈45% reduction)
- [ ] All three non-negotiable safety sections retained verbatim
- [ ] No agent-visible behaviour regression on the standard workflows (`/ship`, `/project-resume`, `/project-new`)
- [ ] User reviews and approves before merge

## Context

CLAUDE.md grew organically over Phases 1–4 and now restates CLI ergonomics (alias tables, directory shortcuts) that are derivable from shell config or are one-off lookups. Phase 5 added three substantial safety sections, pushing it past 145 lines. Cutting refocuses agent attention on the rules that actually shape behaviour. Surfaced during the same Phase 5 grilling that opened T101–T111.
