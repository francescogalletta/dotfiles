# [T129] Remove Obsidian config management; vaults keep settings locally

**Phase:** Phase 7: Claude Code ergonomics
**Status:** `done`
**Owner:** —

## Goal

Stop managing Obsidian config from dotfiles until the user decides how they want to use it, without changing anything either vault currently looks like.

## Acceptance Criteria

- [x] Every live symlink into `config/obsidian/` replaced with a real local file first
- [x] `config/obsidian/`, links.map row, `links.sh` discovery, `local` guard, `sync.sh` vault sync, tests, ignore entry and permissions removed
- [x] README and PRD no longer describe Obsidian config
- [x] Obsidian app install (Brewfile cask) kept
- [x] No symlinks left in either vault's `.obsidian` (Monzo `themes`/`plugins` unlinked)

## Decisions

### 2026-09-28 — Localize before delete; keep the app; vaults fully independent

See ADR-045. Deleting repo files first would have left dangling symlinks and blanked both vaults' settings and Obsidian's vault list. The Monzo vault's `themes`/`plugins` links to the personal vault were then replaced with the restored `.bak` originals plus copies of what only the link supplied, so the vault looks the same and shares nothing.
