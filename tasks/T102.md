# [T102] Remove Discord write pre-approval; keep Gmail draft

**Phase:** Phase 5: Agent config sanity pass
**Status:** `done`
**Owner:** —
**BlockedBy:** —
**Validation:** none, mechanical change, agent can proceed autonomously

## Goal

Remove `mcp__plugin_discord_discord__reply` from `settings.local.json`. Discord replies are public, fan out quickly, and are harder to undo than a Gmail draft sitting locally. The Gmail draft pre-approval (`mcp__claude_ai_Gmail__gmail_create_draft`) stays because the user explicitly wants it.

## Acceptance Criteria

- [ ] `mcp__plugin_discord_discord__reply` removed from `~/.claude/settings.local.json` allow list
- [ ] `mcp__claude_ai_Gmail__gmail_create_draft` still present
- [ ] No other MCP write tools pre-approved unintentionally

## Context

Part of the agentic-safety hardening from ADR-025. The rule says "cloud MCP writes need explicit per-action approval"; this task closes the specific exception that was already in place.

## Decisions

- 2026-05-21: Removed `mcp__plugin_discord_discord__reply` and `mcp__plugin_discord_discord__fetch_messages` from `settings.local.json` allow list. Kept `mcp__claude_ai_Gmail__gmail_get_profile` and `mcp__claude_ai_Gmail__gmail_create_draft` per user direction.
