# [T121] Reformat cheatsheets for glanceability; make the renderer unicode-safe

**Status:** `done`

## Goal

Make the shortcut sheets readable at a glance rather than merely correct.

## Acceptance Criteria

- [x] Symbol notation (`⌥⇧F`) replacing spelled-out modifiers (`alt shift f`), with a legend line
- [x] Key column padded in the markdown source, so the raw file reads as a table too
- [x] Renderer pads per table rather than per file, so short-key sections stay narrow
- [x] `**bold**` converted to ANSI instead of leaking asterisks
- [x] `dwidth()` measures display width, not bytes
- [x] `test.sh`: markdown-leak check extended to `**`; new per-table alignment check
- [x] Alignment check proven to fail on an unknown glyph, then restored

## Context

T120 built the renderer against a sheet written in ASCII, so byte-vs-character width never came up. Switching to modifier symbols exposed it immediately.

## Decisions

### 2026-08-15 — Symbols over spelled-out modifiers

`⌥⇧ H/J/K/L` scans faster than `alt shift h/j/k/l` and matches every other macOS shortcut reference. The cost is that searching the sheets for "alt" no longer matches; searching by action text is unaffected, and that is how the search is actually used. A legend line at the top carries the mapping. `aerospace.toml` keeps its own `alt-shift-h` spelling since that is AeroSpace's config syntax, not a display choice.

### 2026-08-15 — dwidth(), because macOS awk counts bytes

macOS ships awk 20200816, which measures `length()` in bytes. Each modifier glyph is 3 bytes, so `printf "%-10s"` on `⌥⇧F` emitted 6 spaces too few and every column below it shifted. The generic fixes do not work in this awk: `gsub(/[\200-\277]/, ...)` matches nothing, so continuation bytes cannot be counted. `dwidth()` therefore normalises a known glyph vocabulary to one byte before measuring. Adding a glyph outside that list costs alignment, not correctness, which is exactly what the new test catches.

Rejected: rewriting the renderer in perl for native unicode. It would work, but it trades a 30-line dependency-free awk block for a second language in a script whose only job is printing a table.

### 2026-08-15 — Per-table column width

One width for the whole file meant the Workspaces section (`⌥⇥`, 2 characters) inherited the widest key on the sheet (`⌥⇧ H/J/K/L`, 10) and sat in a column of whitespace. Width is now computed per contiguous table block.
