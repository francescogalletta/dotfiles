# [T124] Make the focus highlight readable at a glance; unfocused windows lose their border

**Phase:** Phase 7: Claude Code ergonomics
**Status:** `done`
**Owner:** —
**BlockedBy:** —
**Validation:** `./test.sh` 33/33; `tomllib` parse; `aerospace reload-config --dry-run --warnings-as-errors`; candidates scored before selection and previewed on the live `borders` process before commit

## Goal

Make the focused window identifiable without looking for it. T123 did not achieve this.

## Acceptance Criteria

- [x] `active_color=0xff00e676`, `inactive_color=0x00000000`, `width=8.0`
- [x] Unfocused windows draw no border at all
- [x] Gaps stay at 6, the separation fix from T123 is not reopened
- [x] Selection made on a metric that predicts glanceability, not contrast alone
- [x] ADR-040 amended rather than superseded

## Context

Sage `#a3b18a` shipped in T123 and was rejected in use as still hard to tell apart at a glance. Second miss on the same complaint.

## Decisions

### 2026-08-16 — Contrast was the right rebuttal and the wrong selection metric

T123 correctly established that the original grey-on-grey pair was not a contrast failure (6.45:1). It then wrongly carried contrast forward as the criterion for picking the replacement. Scoring candidates as contrast × HLS saturation against the `#1e1e2e` base:

| Colour | Contrast | Saturation | Score |
|---|---|---|---|
| sage `#a3b18a` (T123) | 7.20:1 | 20% | **1.4** |
| Mocha red `#f38ba8` | 7.08:1 | 81% | 5.8 |
| Mocha green `#a6e3a1` | 11.03:1 | 54% | 6.0 |
| Mocha teal `#94e2d5` | 11.01:1 | 57% | 6.3 |
| Mocha mauve `#cba6f7` | 8.07:1 | 84% | 6.7 |
| Mocha peach `#fab387` | 9.27:1 | 92% | 8.5 |
| **vivid green `#00e676`** | 9.83:1 | 100% | **9.8** |
| Mocha yellow `#f9e2af` | 12.91:1 | 86% | 11.1 |
| chartreuse `#7cfc00` | 12.33:1 | 100% | 12.3 |

Sage ranks last of everything measured. A 20%-saturated colour reads as another shade of grey no matter how cleanly it separates on luminance, which is the same failure mode as the original complaint wearing a different hex. Yellow and chartreuse scored higher and were offered; vivid green was chosen, keeping the green family without the desaturation.

### 2026-08-16 — Transparent inactive is the lever that actually worked

`inactive_color=0x00000000`. Alpha `00` means unfocused windows draw nothing, so exactly one border exists on screen and identifying focus requires no comparison between two colours. This was available from the start and went unused for two rounds while both attempts tuned the colour pair instead. It is strictly stronger than any choice of inactive colour, because it removes the comparison rather than making it easier.

Consequence worth noting: total border clutter drops versus any opaque inactive. Previously all six open windows drew an outline; now one does.

### 2026-08-16 — Width back to 8.0 without reopening the gaps complaint

T123 cut `width` 8.0 → 4.0 in the same commit as the colour change, serving the separation complaint at the highlight's expense. With a transparent inactive the two goals stop competing: thickness now applies to a single window rather than every window, so 8.0 is bold where it matters and invisible everywhere else. `gaps` stay at 6.
