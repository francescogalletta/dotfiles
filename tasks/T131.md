## Decisions

### 2026-11-11 — Prompt, not a silent opt-out

A first cut skipped silently on a flag. The user preferred the sync to offer the choice, so the prompt was added before push. The flag stays as the remembered answer. See ADR-047.

### 2026-11-11 — Guard in `links.map`, flag in `~/.gitconfig.local`

Reuses the existing guard mechanism (ADR-034) and the existing generated per-machine file rather than a new marker.
