# [T115] Retire `templates/` archetypes; `/project-new` becomes docs-only scaffolder

**Phase:** Phase 5: Agent config sanity pass
**Status:** `done`
**Owner:** —
**BlockedBy:** —
**Validation:** user confirmed: "delete the archetypes altogether"

## Goal

Remove all five `templates/` archetypes (`data`, `web`, `api`, `cli`, `agent`) and rewrite `/project-new` to skip archetype selection. Container infra is now built agentically per-project rather than copied from a frozen template.

## Acceptance Criteria

- [x] `templates/` directory deleted (all 5 archetypes, 62 files)
- [x] `/project-new` rewritten: no archetype menu, no template copy, no uv-lock step, no Phase 4 `make dev` prompt
- [x] `Brewfile` drops `flyctl` and `gcloud-cli` (only used by retired `/graduate`)
- [x] References cleaned in `CLAUDE.md`, `PRD.md`, `README.md`, `config/claude/skills/learn/SKILL.md`
- [x] T108 + T110 dropped from index; task files deleted
- [x] ADR-029 prepended

## Context

`/project-new` had 0 invocations in the last 30 days (T107 audit) and only 2 all-time. The archetypes inside it committed to a stack decision before any project requirements existed — wrong order. Agentic scaffolding lets the stack emerge from real requirements: same files, generated when they're needed, tuned to the project. The user signalled this directly in session 25: "delete the archetypes altogether."

## Decisions

### 2026-05-23 — Keep `/project-new` (docs-only) rather than retire it

Considered retiring `/project-new` entirely (since archetypes were its main differentiator). Kept it because the docs + `.claude/` scaffolding (CLAUDE.md, PRD, TASKS, ADR, per-task files, project-local Claude Code config) is still real work worth automating. User confirmed.

### 2026-05-23 — Drop T108 + T110 by deletion, not "won't do" marker

User chose hard deletion over `won't do` status. Cleaner index; the git history preserves what was there if needed.

### 2026-05-23 — Leave T109 in index with a note

T109 (added `tests/` to `data` and `agent` archetypes) was shipped earlier in session 25 alongside T107. With archetypes now gone the work is moot, but rather than re-edit the index to remove it (and create a confusing-looking gap), left as `done` with `*(work now moot — archetypes retired in T115)*` annotation.

## Notes

### 2026-05-23 — Brewfile cleanup verified

`flyctl` and `gcloud-cli` had no other consumers (no scripts, no aliases, no zshrc refs). Safe to remove. User has them installed locally; removing from Brewfile means they won't be re-installed on a fresh machine.
