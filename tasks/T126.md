# [T126] Make the reconcile path remove, not just add

**Phase:** Phase 7: Claude Code ergonomics
**Status:** `done`
**Owner:** —
**BlockedBy:** —
**Validation:** `./test.sh` 37/37; `sync.sh` run repeatedly against a live Google Drive vault — prune removes real orphans, vault-sync rolls back instead of clobbering, second run idempotent, personal vault's themes/plugins survive intact

## Goal

Close the parity gap surfaced by a second-laptop `git pull`: the setup scripts only ever add or relink, so retiring a config leaves broken symlinks and empty dirs behind, and the new Homebrew tap-trust gate aborts `brew bundle` on a fresh machine.

## Acceptance Criteria

- [x] `sync.sh` prunes broken symlinks that point into `$DOTFILES`, scoped to the managed roots
- [x] A prune that empties a dir under `~/.config` removes the dir too
- [x] Broken symlinks pointing outside `$DOTFILES` are left untouched
- [x] Obsidian vault-sync can never replace a target's real config with a link to an unmaterialized (cloud placeholder) source — attempt, verify, roll back
- [x] `install.sh` pre-trusts every `tap` declared in the Brewfile before `brew bundle`
- [x] `test.sh` asserts no orphaned dotfiles symlinks remain; passes in CI and on a synced machine

## Context

Triggered while bringing a second laptop to parity after `git pull`. `sync.sh` relinked the stale `~/.aerospace.toml` correctly, but three gaps showed up: tmux (retired in ADR-034) was still installed with a dangling `~/.config/tmux/tmux.conf`; `borders` wouldn't install because `felixkratz/formulae` hit Homebrew's third-party-tap trust gate; and `sync.sh`'s Obsidian vault-sync twice ate the personal vault's themes/plugins by symlinking them at a Google Drive placeholder that stats as a real directory but doesn't resolve.

## Decisions

### 2026-08-17 — Prune only what is provably ours, roll back what cloud storage lies about

A broken symlink into `$DOTFILES` is the only thing safe to auto-remove: a live `links.map` row would have relinked it on the same run, so a survivor is the fossil of a deleted row. Symmetric package removal (`brew bundle cleanup`) was rejected — it would uninstall the unmanaged-on-purpose tools of ADR-035. For the vault-sync, no `[ -d ]`/`ls -A` precheck survives Google Drive lazy-materialization, so the link is attempted and verified, and the target's backup restored if it dangles. See ADR-042.
