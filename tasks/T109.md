## Goal

Make all template archetypes consistent. Currently `api/` and `cli/` ship with a `tests/` directory; `data/` and `agent/` do not. Add a minimal `tests/` directory (with `__init__.py` + one example pytest file) to both.

## Acceptance Criteria

- [ ] `templates/data/tests/` exists with `__init__.py` and `test_smoke.py`
- [ ] `templates/agent/tests/` exists with `__init__.py` and `test_smoke.py`
- [ ] Both `tests/` directories include a smoke test that runs `make test` cleanly inside the container
- [ ] `pyproject.toml` in each archetype includes pytest as a dev dependency (if not already)

## Context

Found during the grilling review of templates. Inconsistency is minor but causes the agent to scaffold without tests for half the archetypes, then add them later with no convention guidance.
