## Goal

Ground the keep/cut decisions for custom skills in evidence rather than guesswork. Search `~/.claude/projects/**/*.jsonl` for slash-command invocations of `/explain`, `/graduate`, `/learn`, `/project-new`, `/project-resume`, `/ship`, `/slides` over the last 30 days. Present the counts. Delete anything that fired 0 times.

## Acceptance Criteria

- [ ] Usage report produced: skill name → count of invocations in last 30 days
- [ ] Report includes both user-typed invocations and model-triggered ones (if distinguishable)

## Context

Without usage signal, the skills directory becomes a museum. Several skills (`/graduate`, `/explain`, possibly `/slides`) may not have fired in months. Evidence-driven pruning prevents the agent prompt from being polluted with dead skill descriptions.

### 2026-05-23 — Reproducible audit command

```bash
# User-typed (slash command in chat)
find ~/.claude/projects -name "*.jsonl" -exec grep -hoE '<command-name>/[a-z-]+' {} \; \
  | sort | uniq -c | sort -rn

# Model-triggered (Skill tool calls)
find ~/.claude/projects -name "*.jsonl" -exec grep -hoE '"name":"Skill"[^}]*"skill":"[a-z-]+' {} \; \
  | grep -oE '"skill":"[a-z-]+' | sort | uniq -c | sort -rn

# Add `-mtime -30` to restrict to last 30 days.
```
